# Security Policy

We take the security of this project seriously. If you discover a security vulnerability, please do not create a public issue. Instead, report it privately using the method below.

## Reporting a Vulnerability

Vulnerabilities can be reported securely and privately through GitHub's built-in system.

1. Click on the **"Security and quality"** tab at the top of this repository.
2. Click the **"Report a vulnerability"** button, fill in the details, and submit.

Your report will remain private and will only be visible to the project maintainers.

## Our Commitment

Upon receiving a report, we will promptly review the details and work on a security patch. The vulnerability details will be kept confidential until a fix is completed and an update is made available to our users.
